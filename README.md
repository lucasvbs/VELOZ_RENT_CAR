# Veloz Rent a Car

Landing page da Veloz Rent a Car para motoristas de aplicativo em Salvador e região.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Produção

```sh
npm run build
```

O site é uma aplicação Vite estática; o build de produção é gerado em `dist/`. A configuração da Vercel publica essa pasta e mantém o fallback da aplicação.
